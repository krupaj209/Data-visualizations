# Visitor Question Bank v3

---

## Standard questions — every CE gets these automatically

These four apply universally wherever the data exists. The orchestrator includes
them by default and skips only if the DRD explicitly flags them as inapplicable.

| # | Question | Viz type | Skip if |
|---|---|---|---|
| S1 | When do the crowds show? | `weekly_pattern` + `hourly_heatmap` | CE has no crowd variability (e.g. private charter) |
| S2 | Choose the right entry lane | `queue_compare` | CE has no physical queue or single-lane entry |
| S3 | How early should you book? | `booking_window` | CE has unlimited capacity / no sell-out risk |
| S4 | How long should I spend here? | `duration_stat` | CE is fixed-duration (exact runtime known) |

*Note: S1 maps to the two-panel layout shown in the Accademia screenshots —
weekly bar chart with colour bands (quietest → as busy as it gets) on the left,
smooth hourly curve with Best / Peak / 2nd best zones on the right.*

---

## Signature questions — subcat-specific, data-dependent

The orchestrator adds 1–3 signature questions per CE on top of the four standards.
Each signature question requires a distinct data signal not covered by S1–S4.
Questions are only included if the DRD contains the relevant data.

---

**Museums**
| Question | Viz type | Data signal |
|---|---|---|
| Which galleries are busiest — and when should you visit each? | `zone_crowd_heatmap` | Visitor flow by gallery × hour |
| Which ticket tier gives the best access for the price? | `ticket_ladder` | Access level + queue time + price by tier |
| What share of visitors buy skip-the-line? | `donut_breakdown` | Ticket type sales mix |

*The zone_crowd_heatmap is the signature viz here — rows are named galleries,
columns are hours, colour is crowd level. Tells visitors exactly when to hit
the Sistine Chapel vs the Raphael Rooms.*

**Theme Parks**
| Question | Viz type | Data signal |
|---|---|---|
| When's the best window to ride [headline attraction]? | `ride_wait_curve` | Hourly wait time for the named ride |
| Which rides have the shortest waits right at opening? | `opening_hour_rank` | Wait times 9–10am, ranked shortest to longest |
| How do wait times compare across the named lands throughout the day? | `zone_wait_heatmap` | Wait time by zone × hour |
| Which pass tier actually saves the most time — not just money? | `ticket_ladder` | Wait time with standard queue vs pass, per headline ride |
| Which dates in the next 3 months are calmest? | `month_calendar` | Day-level crowd index |

*ride_wait_curve is the theme park equivalent of the Accademia hourly crowd curve —
same shape, same Best/Peak/2nd best zones, but y-axis is wait time in minutes
not relative crowd level. One curve per headline ride. This is the signature question
that no other subcat has.*

*opening_hour_rank is the "rope drop" question — which rides to sprint to first.
Bar chart ranked shortest to longest morning wait. Actionable within the first
30 minutes of arrival.*

### Tours

**Guided Tours**
| Question | Viz type | Data signal |
|---|---|---|
| What share of guests pick private vs shared, and why does it matter? | `donut_breakdown` | Tier sales mix + avg group size per tier |
| How is the time actually split — travel, queuing, and time at the site? | `time_split` | Duration breakdown: transit / queue / at-site / breaks |

*time_split is a stacked horizontal bar — transit (grey) / queue (amber) / at-site (green) / breaks.
The honest version of the question "how long is the tour" — shows how much of that time
is actually spent at the thing you came to see.*

| How long do you actually wait at each stop? | `stop_frequency` | Bus headway by stop × time of day |

*stop_frequency: the practical question HOHO visitors actually have.

## Viz type reference

| Type | Description | Y-axis |
|---|---|---|
| `weekly_pattern` | Bar chart by day of week, colour-banded | Crowd index |
| `hourly_heatmap` | Smooth curve with Best/Peak/2nd best zones | Crowd level (default), or wait time, or journey time |
| `booking_window` | Bar chart of % bookings by lead-time bucket | % of bookings (default), or price index |
| `queue_compare` | Visual queue diagram with wait-time badges | Wait time per entry lane |
| `duration_stat` | Stat grid with median duration, range, and visitor-type breakdown | Minutes/hours |
| `ride_wait_curve` | Hourly wait curve per named ride — same format as hourly_heatmap | Wait time in minutes |
| `opening_hour_rank` | Bar chart of ride wait times at rope drop, ranked shortest to longest | Wait time in minutes |
| `zone_wait_heatmap` | Grid: rows = park zones, columns = hours, colour = wait time | Wait time in minutes |
| `zone_crowd_heatmap` | Grid: rows = named zones/galleries, columns = hours, colour = crowd | Crowd level |
| `zone_wait_compare` | Side-by-side bars for named zones/routes/options | Varies by context |
| `daily_programme` | Linear timeline of the day with fixed events pinned | Clock time |
| `ticket_ladder` | Ranked tiers comparing price, wait saved, and inclusions | Price + benefit |
| `donut_breakdown` | Share of visitors / bookings by category | % share |
| `month_calendar` | Calendar view of next 3 months, colour-coded by crowd or availability | Crowd / availability |
| `sighting_probability` | Monthly bar chart of % trips with confirmed sightings | % success rate |
| `activity_window` | Smooth curve of animal/wildlife activity by hour | Activity level |
| `departure_reliability` | Monthly bar chart of % sessions that departed as scheduled | % reliability |
| `conditions_calendar` | Monthly chart of conditions quality (snow, visibility, swell, flow) | Conditions index |
| `golden_hour_match` | Month × departure slot matrix, green where they align | Alignment yes/no |
| `slot_compare` | Side-by-side comparison of 2–3 named time slots across multiple dimensions | Multi-axis |
| `time_split` | Stacked horizontal bar: transit / queue / at-site / breaks | Duration in minutes |
| `savings_breakdown` | Horizontal bar per attraction showing standalone price vs card threshold | Price in currency |
| `return_buffer_rank` | Bars per tour option showing minutes of buffer before ship departure | Minutes |
| `seat_value_map` | Simplified seatmap colour-coded by price-to-view-quality ratio | Value index |
| `optimal_departure` | Departure slots rated on light quality, conditions, and crowd | Multi-factor score |
| `price_curve` | Price index by departure date or booking lead time | Price index |
| `stop_frequency` | Bus headway by stop in peak vs off-peak | Minutes between buses |
