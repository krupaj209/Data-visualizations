Now I have the full picture. Here's the **Question Registry v2** design that layers on top of your existing Task #99 bundle engine without replacing it.

## Architecture: 3-Layer Registry with DB Merge

```
┌─────────────────────────────────────────────────────────┐
│  LAYER 1: CODE (Universal)                              │
│  - Archetype definitions (types.ts)                       │
│  - Subcategory registry (bank.ts)                         │
│  - Intent definitions (intents.ts)                        │
│  - Signal extractor (signals.ts)                          │
│  - Bundle definitions (bundles.ts) ← YOU KEEP THIS        │
│  - Page templates (page-templates.ts)                     │
│  - Universal question overrides (new: universal-questions.ts) │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│  LAYER 2: DB (Category + CE Overrides)                  │
│  - question_category_overrides (per-subcategory)        │
│  - question_ce_overrides (per-CE)                       │
│  Both store: add/remove/reorder/scoreBoost/blockWhen     │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│  MERGE ENGINE (new: registry-v2.ts)                      │
│  1. Load bundle from code                                 │
│  2. Apply category overrides from DB                      │
│  3. Apply CE overrides from DB                            │
│  4. Run enhanced decision engine with per-question scoring │
│  5. Return merged bundle → existing assembler             │
└─────────────────────────────────────────────────────────┘
```

## Why This Design

| Your Concern | How This Solves It |
|-------------|-------------------|
| "Improve the question bank" | DB overrides let content team tune without code deploys |
| "Edit/remove/add questions" | `question_category_overrides` table with CRUD API |
| "Update for entire subcat/cat" | Category overrides apply to all CEs in that subcategory |
| "Filter for category/subcat" | Studio UI queries `question_category_overrides` by subcategory_id |
| "Make it more intelligent" | Per-question `scoreBoost`, `blockWhen`, `trigger` conditions |
| "Layout improvements" | Studio UI with filter sidebar + editable table |

```typescript
 * Question Registry v2 — 3-layer signal-driven registry.
 * 
 * Layers:
 *   1. CODE: Bundles, archetypes, intents, signals (existing Task #99)
 *   2. DB: Category overrides (per-subcategory) + CE overrides (per-CE)
 *   3. MERGE: Runtime assembly with per-question scoring
 * 
 * This extends (not replaces) the existing bundle engine. The assembler
 * in assembler.ts continues to work unchanged — it receives a merged
 * bundle from this layer.
 */

import type { ChartArchetypeId } from "./types";
import type { BundleId, BundleCandidate, QuestionBundle } from "./bundles";
import type { ContextSignals } from "./signals";
import type { VisitorIntentId } from "./intents";
import type { SubcategoryId } from "./types";

export interface CategoryQuestionOverride {
  id: string;                    // UUID
  subcategory_id: SubcategoryId;
  bundle_id: BundleId;
  
  // Override type
  action: "add" | "remove" | "reorder" | "score_boost" | "block_when";
  
  // For "add": new candidate to inject
  added_candidate?: {
    archetype: ChartArchetypeId;
    question_template: string;
    requires?: (keyof ContextSignals)[];
    prefers?: (keyof ContextSignals)[];
    kind?: "standard" | "signature";
    position?: "first" | "last" | number;  // Where to insert in candidate list
  };
  
  // For "remove": which archetype to suppress
  removed_archetype?: ChartArchetypeId;
  
  // For "reorder": new ordering of archetypes
  reordered_archetypes?: ChartArchetypeId[];
  
  // For "score_boost": boost this archetype's score
  score_boost?: {
    archetype: ChartArchetypeId;
    boost: number;             // Add to bundle score (e.g., +5)
    condition?: string;        // Only apply when condition met (see TriggerCondition)
  };
  
  // For "block_when": suppress when condition met
  block_when?: {
    archetype: ChartArchetypeId;
    condition: TriggerCondition;
    reason: string;            // Shown in dropped[] audit
  };
  
  // Metadata
  created_by: string;          // User ID
  created_at: Date;
  updated_at: Date;
  notes?: string;
}

export interface CEQuestionOverride {
  id: string;                  // UUID
  ce_slug: string;
  subcategory_id: SubcategoryId;
  bundle_id: BundleId;
  
  action: "force_include" | "force_exclude" | "score_boost" | "swap_template";
  
  // Force include: add this archetype even if signals don't match
  force_include?: {
    archetype: ChartArchetypeId;
    question_template: string;
    position?: "first" | number;
    reason: string;
  };
  
  // Force exclude: never show this archetype for this CE
  force_exclude?: {
    archetype: ChartArchetypeId;
    reason: string;
  };
  
  // Score boost: per-CE tuning
  score_boost?: {
    archetype: ChartArchetypeId;
    boost: number;
  };
  
  // Swap template: use different question wording for this CE
  swap_template?: {
    archetype: ChartArchetypeId;
    new_template: string;
  };
  
  created_by: string;
  created_at: Date;
  updated_at: Date;
  notes?: string;
}

// ─────────────────────────────────────────────────────────────────────────
// Trigger Conditions (for block_when, score_boost condition)
// ─────────────────────────────────────────────────────────────────────────

export type TriggerCondition =
  | { type: "signal_present"; signal: keyof ContextSignals }
  | { type: "signal_absent"; signal: keyof ContextSignals }
  | { type: "page_type"; pageType: string }
  | { type: "ce_slug"; ceSlug: string }
  | { type: "subcategory"; subcategoryId: SubcategoryId }
  | { type: "season"; months: number[] }
  | { type: "and"; conditions: TriggerCondition[] }
  | { type: "or"; conditions: TriggerCondition[] };

export function evaluateTrigger(
  condition: TriggerCondition,
  signals: ContextSignals,
  pageType: string,
  ceSlug: string,
  subcategoryId: SubcategoryId,
  currentMonth?: number,
): boolean {
  switch (condition.type) {
    case "signal_present":
      return Boolean(signals[condition.signal]);
    case "signal_absent":
      return !Boolean(signals[condition.signal]);
    case "page_type":
      return pageType === condition.pageType;
    case "ce_slug":
      return ceSlug === condition.ceSlug;
    case "subcategory":
      return subcategoryId === condition.subcategoryId;
    case "season":
      return currentMonth ? condition.months.includes(currentMonth) : false;
    case "and":
      return condition.conditions.every(c =>
        evaluateTrigger(c, signals, pageType, ceSlug, subcategoryId, currentMonth)
      );
    case "or":
      return condition.conditions.some(c =>
        evaluateTrigger(c, signals, pageType, ceSlug, subcategoryId, currentMonth)
      );
  }
}

/**
 * Merge a code bundle with DB overrides to produce a MergedQuestionBundle.
 * This is the core of Registry v2 — deterministic, testable, auditable.
 */
export function mergeBundle(input: MergeInput): MergedQuestionBundle {
  const baseBundle = QUESTION_BUNDLES[input.bundleId];
  const candidates: MergedBundleCandidate[] = baseBundle.candidates.map((c, i) => ({
    ...c,
    override_source: "code",
    original_index: i,
    score_modifier: 0,
  }));

  const audit = {
    category_overrides_applied: [] as string[],
    ce_overrides_applied: [] as string[],
    candidates_added: 0,
    candidates_removed: 0,
    candidates_reordered: false,
    score_modifiers_applied: 0,
  };

  // ── Apply category overrides ──
  for (const override of input.categoryOverrides) {
    if (override.bundle_id !== input.bundleId) continue;
    
    switch (override.action) {
      case "add": {
        if (override.added_candidate) {
          const pos = override.added_candidate.position === "first" ? 0 :
                     override.added_candidate.position === "last" ? candidates.length :
                     override.added_candidate.position ?? candidates.length;
          candidates.splice(pos, 0, {
            ...override.added_candidate,
            override_source: "category_db",
            original_index: -1,
            score_modifier: 0,
          });
          audit.candidates_added++;
        }
        audit.category_overrides_applied.push(override.id);
        break;
      }
      
      case "remove": {
        if (override.removed_archetype) {
          const idx = candidates.findIndex(c => c.archetype === override.removed_archetype);
          if (idx >= 0) {
            candidates.splice(idx, 1);
            audit.candidates_removed++;
          }
        }
        audit.category_overrides_applied.push(override.id);
        break;
      }
      
      case "reorder": {
        if (override.reordered_archetypes) {
          const newOrder: MergedBundleCandidate[] = [];
          for (const arch of override.reordered_archetypes) {
            const found = candidates.find(c => c.archetype === arch);
            if (found) newOrder.push(found);
          }
          // Append any not in the reorder list
          for (const c of candidates) {
            if (!override.reordered_archetypes.includes(c.archetype)) {
              newOrder.push(c);
            }
          }
          candidates.length = 0;
          candidates.push(...newOrder);
          audit.candidates_reordered = true;
        }
        audit.category_overrides_applied.push(override.id);
        break;
      }
      
      case "score_boost": {
        if (override.score_boost) {
          const c = candidates.find(c => c.archetype === override.score_boost!.archetype);
          if (c) {
            // Only apply if condition passes (or no condition)
            if (!override.score_boost.condition ||
                evaluateTrigger(
                  override.score_boost.condition,
                  input.signals,
                  input.pageType,
                  input.ceSlug,
                  input.subcategoryId,
                  input.currentMonth
                )) {
              c.score_modifier = (c.score_modifier ?? 0) + override.score_boost.boost;
              audit.score_modifiers_applied++;
            }
          }
        }
        audit.category_overrides_applied.push(override.id);
        break;
      }
      
      case "block_when": {
        if (override.block_when) {
          const c = candidates.find(c => c.archetype === override.block_when!.archetype);
          if (c) {
            const triggered = evaluateTrigger(
              override.block_when.condition,
              input.signals,
              input.pageType,
              input.ceSlug,
              input.subcategoryId,
              input.currentMonth
            );
            if (triggered) {
              c.blocked = {
                by: override.id,
                reason: override.block_when.reason,
                condition: override.block_when.condition,
              };
            }
          }
        }
        audit.category_overrides_applied.push(override.id);
        break;
      }
    }
  }

  // ── Apply CE overrides ──
  for (const override of input.ceOverrides) {
    if (override.bundle_id !== input.bundleId) continue;
    
    switch (override.action) {
      case "force_include": {
        if (override.force_include) {
          const pos = override.force_include.position === "first" ? 0 :
                     override.force_include.position ?? 0;
          candidates.splice(pos, 0, {
            archetype: override.force_include.archetype,
            question_template: override.force_include.question_template,
            override_source: "ce_db",
            original_index: -1,
            score_modifier: 100, // Massive boost to ensure selection
          });
          audit.candidates_added++;
        }
        audit.ce_overrides_applied.push(override.id);
        break;
      }
      
      case "force_exclude": {
        if (override.force_exclude) {
          const idx = candidates.findIndex(c => c.archetype === override.force_exclude!.archetype);
          if (idx >= 0) {
            candidates.splice(idx, 1);
            audit.candidates_removed++;
          }
        }
        audit.ce_overrides_applied.push(override.id);
        break;
      }
      
      case "score_boost": {
        if (override.score_boost) {
          const c = candidates.find(c => c.archetype === override.score_boost!.archetype);
          if (c) {
            c.score_modifier = (c.score_modifier ?? 0) + override.score_boost.boost;
            audit.score_modifiers_applied++;
          }
        }
        audit.ce_overrides_applied.push(override.id);
        break;
      }
      
      case "swap_template": {
        if (override.swap_template) {
          const c = candidates.find(c => c.archetype === override.swap_template!.archetype);
          if (c) {
            c.question_template = override.swap_template.new_template;
          }
        }
        audit.ce_overrides_applied.push(override.id);
        break;
      }
    }
  }

  return {
    ...baseBundle,
    candidates,
    override_audit: audit,
  };
}
```

### 3. `lib/question-bank/src/assembler-v2.ts` — Enhanced Assembler Using Merged Bundles

```typescript
/**
 * Deck Assembler v2 — uses merged bundles from Registry v2.
 * 
 * Drop-in replacement for assembleDeck() that:
 * 1. Fetches overrides from DB
 * 2. Merges bundles
 * 3. Runs enhanced scoring with per-candidate modifiers
 * 4. Falls back to original assembler if no overrides exist
 */

import { mergeBundle, type MergeInput, type MergedBundleCandidate } from "./registry-v2";
import { QUESTION_BUNDLES, type BundleId, type QuestionBundle } from "./bundles";
import { countSignalMatches, type ContextSignals } from "./signals";
import { getPageTemplate, type PageType, DEFAULT_PAGE_TYPE } from "./page-templates";
import type { VisitorIntentId } from "./intents";
import type { BankQuestionKind, ChartArchetypeId } from "./types";
import type { SubcategoryId } from "./types";
import { isImplementedArchetype } from "./archetypes";

// DB client interface (injected, not imported to avoid circular deps)
export interface OverrideStore {
  getCategoryOverrides(subcategoryId: SubcategoryId, bundleId: BundleId): Promise<any[]>;
  getCEOverrides(ceSlug: string, bundleId: BundleId): Promise<any[]>;
}

export interface AssembleV2Input {
  ceName: string;
  ceSlug: string;
  subcategoryId: SubcategoryId;
  signals: ContextSignals;
  pageType?: PageType;
  retireArchetypes?: ChartArchetypeId[];
  existingArchetypes?: ChartArchetypeId[];
  /** Override store — if not provided, falls back to v1 behavior. */
  overrideStore?: OverrideStore;
  currentMonth?: number;
}

// Re-export v1 types for compatibility
export type { AssembledQuestion, DroppedQuestion, AssembledDeck } from "./assembler";

/**
 * Enhanced pickCandidate that respects score modifiers from merged bundles.
 */
function pickCandidateV2(
  bundle: QuestionBundle & { candidates: MergedBundleCandidate[] },
  signals: ContextSignals,
  usedArchetypes: Set<<ChartArchetypeId>,
  retired: Set<<ChartArchetypeId>,
  preferUnused: Set<<ChartArchetypeId>,
  dropped: { question: string; reason: string }[],
  ceName: string,
): { candidate: MergedBundleCandidate; reason: string } | null {
  // Sort by: (original index) + (score modifier) — higher is better
  const scored = bundle.candidates.map(c => ({
    ...c,
    effective_score: (c.score_modifier ?? 0) + (c.original_index ?? 0) * 0.1,
  })).sort((a, b) => b.effective_score - a.effective_score);

  const seen = new Set<<ChartArchetypeId>();
  
  for (const c of scored) {
    if (seen.has(c.archetype)) continue;
    seen.add(c.archetype);

    // Check blocked
    if (c.blocked) {
      dropped.push({
        question: c.question_template.replace(/\{\{ceName\}\}/g, ceName),
        reason: `blocked_by_override: ${c.blocked.reason} (condition: ${JSON.stringify(c.blocked.condition)})`,
      });
      continue;
    }

    if (retired.has(c.archetype)) {
      dropped.push({
        question: c.question_template.replace(/\{\{ceName\}\}/g, ceName),
        reason: `retired_archetype: ${c.archetype}`,
      });
      continue;
    }

    if (!isImplementedArchetype(c.archetype)) {
      dropped.push({
        question: c.question_template.replace(/\{\{ceName\}\}/g, ceName),
        reason: `viz_not_yet_built: ${c.archetype}`,
      });
      continue;
    }

    const requires = c.requires ?? [];
    const missing = requires.filter((s) => !signals[s]);
    if (missing.length > 0) {
      dropped.push({
        question: c.question_template.replace(/\{\{ceName\}\}/g, ceName),
        reason: `signal_missing: needs ${missing.join(", ")}`,
      });
      continue;
    }

    const source = c.override_source === "code" ? "bundle default" :
                   c.override_source === "category_db" ? "category override" :
                   "CE override";

    return {
      candidate: c,
      reason: `bundle "${bundle.id}" selected via ${source} (score_mod: ${c.score_modifier ?? 0})`,
    };
  }
  
  return null;
}

export async function assembleDeckV2(input: AssembleV2Input): Promise<any> {
  // If no override store, fall back to v1 (existing behavior)
  if (!input.overrideStore) {
    const { assembleDeck } = await import("./assembler");
    return assembleDeck({
      ceName: input.ceName,
      signals: input.signals,
      pageType: input.pageType,
      retireArchetypes: input.retireArchetypes,
      existingArchetypes: input.existingArchetypes,
    });
  }

  const pageType = input.pageType ?? DEFAULT_PAGE_TYPE;
  const template = getPageTemplate(pageType);
  const retired = new Set<<ChartArchetypeId>(input.retireArchetypes ?? []);
  const existing = new Set<<ChartArchetypeId>(input.existingArchetypes ?? []);
  const usedArchetypes = new Set<<ChartArchetypeId>();
  const usedBundles = new Set<<BundleId>();
  const selected: any[] = [];
  const dropped: any[] = [];
  const audit: any[] = [];

  for (const slot of template.slots) {
    if (selected.length >= template.maxCharts) break;

    if (slot.forcedArchetype) {
      // ... same as v1 ...
      continue;
    }

    if (!slot.bundleId) continue;
    if (usedBundles.has(slot.bundleId)) {
      audit.push({
        bundle_id: slot.bundleId,
        fired: false,
        notes: ["bundle already fired"],
      });
      continue;
    }

    // ── REGISTRY V2: Merge bundle with overrides ──
    const [catOverrides, ceOverrides] = await Promise.all([
      input.overrideStore!.getCategoryOverrides(input.subcategoryId, slot.bundleId),
      input.overrideStore!.getCEOverrides(input.ceSlug, slot.bundleId),
    ]);

    const merged = mergeBundle({
      bundleId: slot.bundleId,
      subcategoryId: input.subcategoryId,
      ceSlug: input.ceSlug,
      signals: input.signals,
      pageType,
      currentMonth: input.currentMonth,
      categoryOverrides: catOverrides,
      ceOverrides: ceOverrides,
    });

    // Score using merged bundle
    const counts = countSignalMatches(
      input.signals,
      merged.required_signals,
      merged.preferred_signals,
    );
    const triggered = [
      ...merged.required_signals.filter((s) => Boolean(input.signals[s])),
      ...merged.preferred_signals.filter((s) => Boolean(input.signals[s])),
    ];
    const score = 1 + counts.requiredHits * 2 + counts.preferredHits;

    if (!counts.allRequired) {
      audit.push({
        bundle_id: merged.id,
        intent: merged.intent,
        fired: false,
        score,
        triggering_signals: triggered,
        chosen_archetype: null,
        notes: ["required_signals not satisfied"],
        override_audit: merged.override_audit,
      });
      if (slot.required) {
        dropped.push({
          question: `Required ${merged.id} bundle`,
          reason: `bundle_gate_missing: ${merged.required_signals.join(", ")}`,
        });
      }
      continue;
    }

    const picked = pickCandidateV2(
      merged,
      input.signals,
      usedArchetypes,
      retired,
      existing,
      dropped,
      input.ceName,
    );

    if (!picked) {
      audit.push({
        bundle_id: merged.id,
        intent: merged.intent,
        fired: false,
        score,
        triggering_signals: triggered,
        chosen_archetype: null,
        notes: ["no viable candidate"],
        override_audit: merged.override_audit,
      });
      continue;
    }

    const question = picked.candidate.question_template.replace(
      /\{\{ceName\}\}/g,
      input.ceName,
    );

    selected.push({
      question,
      archetype: picked.candidate.archetype,
      rationale: picked.reason,
      kind: picked.candidate.kind ?? "signature",
      bundle_id: merged.id,
      intent_id: merged.intent,
      bundle_score: score,
      triggering_signals: triggered,
      topic_id: merged.id,
      // NEW: v2 provenance
      override_source: picked.candidate.override_source,
      score_modifier: picked.candidate.score_modifier,
    });

    usedArchetypes.add(picked.candidate.archetype);
    usedBundles.add(merged.id);

    audit.push({
      bundle_id: merged.id,
      intent: merged.intent,
      fired: true,
      score,
      triggering_signals: triggered,
      chosen_archetype: picked.candidate.archetype,
      notes: [],
      override_audit: merged.override_audit,
    });
  }

  // ... cap logic same as v1 ...

  return {
    pageType,
    selected,
    dropped,
    bundle_audit: audit,
  };
}
```

## Key Design Decisions

| Decision | Rationale |
|----------|-----------|
| **Bundles stay in code** | They're the structural backbone — changing bundle definitions changes the narrative architecture, which needs dev review |
| **Overrides in DB** | Content team can tune without deploys — this is the agility you need |
| **Merge at runtime** | No build step needed — changes are immediate |
| **Backward compatible** | `assembleDeck` still works — `assembleDeckV2` is opt-in with override store |
| **Audit trail in every merge** | Every decision is traceable: "Why was this question selected?" → "Category override #123 boosted score by +5" |
| **Preview API** | Content team can test changes before saving |
