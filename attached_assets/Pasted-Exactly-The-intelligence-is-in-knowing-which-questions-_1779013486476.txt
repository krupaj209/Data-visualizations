## The Intelligence Model: Three Layers

### Layer 1: Universal Questions (Apply to Most CEs)

These are the "safe" questions that appear unless explicitly blocked:

| Question | Default | Block When |
|----------|---------|-----------|
| "When is it quietest?" | Include | `crowd_variability: none` |
| "How long should I spend?" | Include | `fixed_duration: true` |
| "How far ahead should I book?" | Include | `unlimited_capacity: true` |
| "What do I need to bring?" | Include | `no_restrictions: true` |

### Layer 2: Category-Specific Questions (Apply to Subcategories)

These are gated by subcategory:

| Question | Subcategories | Trigger Signal |
|----------|-------------|----------------|
| "Which entrance do I use?" | Landmarks, Museums, Theme Parks | `entry_points > 1` |
| "Which ride should I do first?" | Theme Parks, Water Parks | `has_headline_attraction: true` |
| "Which seat is worth the premium?" | Entertainment, Sports | `has_seated_venue: true` |
| "Which dive site fits my skill?" | Scuba Diving | `has_multiple_sites: true` |
| "Which trail fits my fitness?" | Hiking | `has_multiple_trails: true` |
| "Which class format fits my group?" | Cooking Classes | `has_multiple_formats: true` |

### Layer 3: CE-Specific Questions (Apply to This Exact CE)

These are triggered by **DRD intelligence**:

| Question | DRD Signal | Example CE |
|----------|-----------|-----------|
| "Is skip-the-line worth it?" | DRD: "standard queue 60-180 min, skip-line 5-10 min" | Colosseum |
| "Should I book the underground tour?" | DRD: "underground requires separate add-on" | Colosseum |
| "Can I visit the Tribune room?" | DRD: "Tribune is the main draw, often crowded" | Accademia |
| "Is the sunset cruise actually at sunset?" | DRD: "sunset departure shifts 5pm-9pm seasonally" | Seine Cruise |
| "Will I see the Big Five?" | DRD: "sighting probability 85% in July, 40% in January" | Safari |

## The Decision Engine

```
Input: CE + DRD + Subcategory

Step 1: Start with universal questions (all included by default)
Step 2: Add category-specific questions (if subcategory matches)
Step 3: Add CE-specific questions (if DRD signals match)
Step 4: Remove questions blocked by CE signals
Step 5: Score remaining questions by DRD confidence
Step 6: Select top N questions for the page type
Step 7: Generate fallback text + embed for each
```
